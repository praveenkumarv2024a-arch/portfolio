## 🚀 How to Host on GitHub Pages

Follow these simple steps to deploy your portfolio live on GitHub Pages:

### Step 1: Initialize Git Repository & Commit Files
Open PowerShell in `c:\portfolioo` and run:
```bash
git init
git add .
git commit -m "Deploy Praveenkumar V Portfolio Website"
```

### Step 2: Create a New GitHub Repository
1. Go to [GitHub](https://github.com/new).
2. Name your repository: `portfolio` (or `praveenkumarv2024a-arch.github.io`).
3. Leave it Public and click **Create repository**.

### Step 3: Connect & Push to GitHub
Run the following commands in PowerShell (replace URL with your repository link):
```bash
git branch -M main
git remote add origin https://github.com/praveenkumarv2024a-arch/portfolio.git
git push -u origin main
```

### Step 4: Enable GitHub Pages
1. On your GitHub repository page, click **Settings** > **Pages** (on the left sidebar).
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be LIVE at:
   `https://praveenkumarv2024a-arch.github.io/portfolio`
